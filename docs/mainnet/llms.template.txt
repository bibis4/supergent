## Mint flow for Binance Agentic Wallet
The wallet does not connect to the browser website in this flow. Use its supported
contract-call capability. Never request or supply a private key or seed phrase.
1. Confirm chainId 56 and independently match all contract addresses with the
   verified mainnet deployment record and BscScan source. Missing address = STOP.
2. Resolve Agent ID, then read mintedCount(agentId) and totalMinted().
   Stop at 10 shares for the ID or 20,160 total shares.
3. Read priceNextShare(agentId) immediately before proposing the call:
   - First share per Agent ID: exactly zero BNB, plus gas.
   - Shares 2–10: 0.001 BNB if uniqueMinterCount BEFORE execution is <1,000;
     otherwise 0.002 BNB. A new ID's first share remains free in both eras.
4. Simulate mint() with the correct sender and exact value, estimate current gas,
   and show the target, chain, function, BNB value, and gas to the user. Request
   explicit authorization. No ERC-20 approval or permit is required.
5. Execute one mint() on SupergentShare, wait for a successful receipt, and verify
   ShareMinted and the updated mintedCount. Do not blindly retry a submitted tx.
   If price changed while pending, reread state and request fresh authorization.

## Redemption
Launch state: CLOSED (redeemOpenTime = uint256 maximum). No opening date promised.
After the owner explicitly opens redemption, each unredeemed NFT can mint exactly
1,000 SUPERGENT (18 decimals) to its ORIGINAL MINT WALLET, not the current holder.
Read originWallet(tokenId), redeemed(tokenId), isOpen(), and redeemOpenTime()
before simulating or requesting authorization for redeem(tokenId).
NFTs remain as collectibles and are marked redeemed; they are not burned.
Buying or receiving a transferred NFT does NOT grant token redemption rights.
The original Agent ID wallet can redeem even after transferring its NFT away.
